# Bus 3 ESP32 Firmware

ESP32 firmware for inductive load monitoring and automatic power factor correction.

## Hardware
- ESP32
- PZEM-004T energy meter
- RL (inductive) load
- Relay module
- Capacitor bank

## Functions
- Monitor voltage, current, power and power factor.
- Detect low power factor.
- Switch capacitor banks through relays.
- Upload electrical measurements to Firebase.
